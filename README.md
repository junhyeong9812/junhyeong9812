# 김준형 | Backend Developer

여러 방법을 직접 실험해 비교하고, 그 데이터로 시스템을 개선해 온 백엔드 개발자입니다.

## [measured-labs](https://github.com/measured-labs) - 직접 만들어 측정하는 실험

실무에서 겪어 보지 못한 문제를 목록으로 만들고, 가설을 세워 하나씩 직접 구현하고 측정해 봅니다. 문제를 풀 때 고를 수 있는 선택지를 넓히려고 계속하고 있습니다.

- [seat-reservation-lab](https://github.com/measured-labs/seat-reservation-lab) - 좌석 경합, 선점 만료, 트래픽 폭주, 조회와 예약의 불일치
- [cache-consistency-lab](https://github.com/measured-labs/cache-consistency-lab) - 오래된 값 노출, 캐시 만료 순간의 폭주, 캐시 장애 때 DB 보호
- [auction-lab](https://github.com/measured-labs/auction-lab) - 최고가 갱신 경합, 마감 직전 입찰 폭주, 낙찰 후 결제 실패
- [log-pipeline-lab](https://github.com/measured-labs/log-pipeline-lab) - 분산 처리와 단일 DB 처리 비교

## [agent-discipline](https://github.com/agent-discipline) - 코딩 에이전트 하네스

코딩 에이전트가 정해진 절차와 규칙으로 일하게 하는 하네스와 규칙, 그리고 그 근거가 되는 실험입니다. measured-labs에서 얻은 결과도 상황별 기준으로 정리해 규칙에 반영합니다.

- [harness](https://github.com/agent-discipline/harness) - 정의, 계획, 개발, 검증, 기록 절차를 훅으로 강제하는 Claude Code 작업 하네스
